# Meme sharing application

## Business Requirement
-A meme sharing social networking web application which allows users to post images/videos as memes. 
-Other people can comment on the meme, like the meme as part of engagement with the meme.
-Document data of users including the memes they have posted and their personal data in a database.
-Users can login or sign up to create an account. During sign up other personal information like profile picture, lives in and caption must be there.
-Users have a separate chat module in which they can chat with other users.
-Users can have friends which are the people that have accepted a friend request.
-Backend must be fastapi python code and frontend we can use react.js
